# 큰 보정 결과와 커브 미세 조절

사용자 첨부 화면에서 세 장 비교와 우측 레벨·커브가 동시에 표시돼 결과가 작았으며, 원본의 큰 여백까지 맞추기 때문에 제품은 더 작았다. 기존 커브는 포인터의 절대 위치를 바로 0~255 값으로 옮겨 작은 드래그에도 값이 크게 바뀌었다.

보정 창은 결과 크게 보기로 시작한다. 원본/누끼/보정 세 장 비교로 전환할 수 있고, 큰 결과에는 제품 맞춤·전체 사진 맞춤과 맞춤 기준 50~300% 확대/축소를 제공한다. 제품 맞춤은 기존 알파 경계로 보기만 확대하고 중심을 맞춘다. 원본 크기 100%는 실제 이미지 픽셀 기준을 유지한다. 확대 상태에서 레벨·커브를 조절해도 스크롤 위치를 유지한다. 보기 설정은 PNG의 해상도/영역/제품 형태를 바꾸지 않는다.

커브는 드래그 시작점에서 상대 이동하며 기본 감도를 기존 1/4, Shift 드래그는 1/20로 낮췄다. 소수 이동을 누적해 천천히 움직여도 값이 변한다. 점을 비스듬히 클릭해도 값이 튀지 않는다. 빈 곳에 점을 만들면 기존 곡선의 해당 밝기 값에서 시작한다. 방향키·숫자 입력·채널·초기화·저장 수치 의미는 유지한다.

검증: 여백이 큰 1000×1000 누끼를 이용해 큰 보기 기본값, 제품 중심 맞춤, 비교 전환, 확대 버튼, 보정 중 스크롤 유지, 8px 드래그 128→130, Shift 20px 128→129, 새 점의 중립 시작, PNG 1000×1000 유지, 모바일 가로 넘침을 검사한다. 실제 누끼 모델을 이용한 기존 색상 조작/적용/설정 이어받기/자동 저장/JSON/재열기/원본 복구도 다시 검사한다. 수정 전 소스는 `2026-10-22-before-large-color-preview`에 보관했다.
