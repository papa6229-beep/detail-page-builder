# 옵션 박스 및 레벨·커브 패치

사용자 요청: 옵션 추가 후 미리보기 박스의 위치/크기 조절 불량을 확인하고 복구. 누끼 보정 창에 수동 레벨·커브를 추가하고 GitHub 및 기존 Vercel 프로젝트로 재배포.

확인 원인: 사진 직접 편집 컨텍스트가 있으면 옵션 Rnd의 drag/resize를 모두 껐다. 사진이 있는 옵션도 사진만 움직이며, 비어 있는 옵션은 컨트롤이 전혀 없다.

범위와 구현 순서:
1. 빈 옵션·사진 옵션에서 박스 전체 편집을 기본으로 복구. 별도 사진 편집 버튼으로 사진의 이동/회전을 유지. 박스 이동·크기 변경은 한 번에 한 단계로 실행 취소하고 문구를 보존. 옵션 추가 시 겹침도 줄인다.
2. 기존 브라우저 픽셀 처리에 수동 레벨(입력 검정/흰색, 감마, 출력 검정/흰색)과 채널 커브(RGB/R/G/B)를 연결. 커브 점 추가·이동·삭제, 숫자 조절, 초기화 제공. 히스토그램은 누끼 원본 밝기 분포. 형태·해상도·알파는 유지하고 색/밝기만 사용자 조절대로 변경.
3. 누끼는 재사용하고 톤→레벨→커브→그림자 순서로 적용. 색상 변경 중 이전 결과의 적용을 막고 최종 미리보기와 저장 PNG를 일치시킨다. 기존 저장 파일은 중립 색상 설정으로 호환. 개별 저장/재열기/JSON/순차 설정 이어받기/원본 사용 지원.
4. 재현 실패→수정→브라우저 조작·수치·기존 기능 회귀→빌드/타입 검사→기존 main 이력 위 커밋/push→Vercel 성공 및 실제 사이트 확인.

기존 원본/설정/사용자 작업은 보존. 변경 전 소스 기준점: `2026-10-22-before-options-levels-curves`. 새 의존성이나 유료 API 없음. 커브 보간은 과도한 진동을 피하는 구간별 3차 보간이며 수학 참고는 SciPy PCHIP 공식 문서.

추가 확인: 새로고침 직후 옵션의 부모 위치 스타일이 적용되기 전에 Rnd가 좌표 차이를 저장하면 카드가 아래로 밀렸다. 좌표 기준 부모의 `position: relative`를 인라인으로 지정해 첫 측정부터 보장하고, 카드 최하단까지 실제 캔버스 높이를 확보했다. 재현 검사에서 기존에는 첫 카드가 다음 카드 및 섹션 바깥으로 침범했고 수정 후 순서/영역 검사가 통과했다.

확인 결과: 옵션 드래그/리사이즈/사진 편집 전환/실행 취소/문구 보존/새로고침/새 카드 비중첩 검사 통과. 레벨·커브 수치 검사 10항목 및 실제 누끼 모델로 조작·PNG 픽셀 비교·이어받기·별도 설정·자동 저장·JSON·재열기·원본 복구 14항목 통과. 버전 3.2.0에 포함한다.
