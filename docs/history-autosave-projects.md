# 이미지 실행 취소·자동 저장·상품별 작업 보관

사용자 승인: 세 기능을 이어서 구현한다. 직관적인 버튼과 현재 편집 흐름을 유지하며 GitHub 푸시·Vercel 배포는 하지 않는다. `2026-10-22-before-history-and-projects`에 직전 상태를 별도 보관했다.

1. 미리보기 이미지 배치와 제품 맞춤을 실행 취소/다시 실행한다. 드래그 한 번은 한 단계, 새로운 조작은 다시 실행 기록을 비운다. 기록은 최대 50단계이고 사진 교체·작업 전환에서 초기화한다. 텍스트는 덮어쓰지 않는다. 입력란/대화상자 안의 Ctrl+Z는 원래 입력 취소로 유지한다.
2. 사진·문구·레이아웃·원본·보정값을 브라우저 IndexedDB에 자동 저장한다. 드래그 중 저장을 미루고 종료 후 짧은 지연으로 저장한다. 화면에 복구 중/저장 대기/저장 중/저장됨/실패를 구분한다. 처음 복구가 끝나기 전에는 빈 화면을 저장하지 않는다. 새로 열면 마지막 작업을 복원한다. API 연결 키는 작업 데이터와 별도이므로 저장하지 않는다.
3. 작업 보관함에서 새 상품, 기존 상품 열기, 현재 작업 이름 변경을 지원한다. 현재 작업을 먼저 저장한 뒤 전환하며 기존 작업을 덮어쓰거나 삭제하지 않는다. 목록에는 이름·저장 시간·사진 수를 표시한다. 기존 ‘임시 저장’은 즉시 저장, ‘불러오기’는 보관함으로 연결한다. 이전 임시 저장 데이터는 보존·가져오기하며 작업 JSON 내보내기/가져오기도 지원한다.

구현: 문서 상태와 이미지 히스토리를 동기적으로 관리하는 저장소 → 포인터 시작/끝 묶음 및 단축키 → 원자적 문서/목록 저장과 현재 작업 포인터 → 자동 저장/복구/전환 → 보관함 UI와 호환 연결. 외부 저장 서비스·새 의존성·유료 호출 없음.

검증: 한 드래그 한 단계, 회전/크기/초기화/제품 맞춤 취소, 다시 실행 및 분기, 텍스트 보존/입력 중 단축키, 새로고침 복원, 사진 포함 두 작업 간 전환과 독립성, 이름·JSON 가져오기/내보내기, 이전 임시 저장, 실패 시 기존 자료 유지, 저장 중 이전 요청의 상태 표시 방지, 기존 이미지/간격/출력 회귀 및 빌드·화면 확인.

## 구현 완료

- 미리보기 상단에 되돌리기/다시 실행, Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y 연결. 포인터 조작은 한 번에 한 단계, 텍스트 입력의 기본 취소는 유지. 제품 맞춤 및 배치 초기화도 기록. 사진 교체와 작업 전환 시 호환되지 않는 기록 초기화.
- 브라우저 IndexedDB에 사진·문구·레이아웃·원본·보정값 자동 저장. 변경 후 600ms, 드래그 중에는 미루고 종료 후 저장. 헤더에 상태 표시. 마지막 작업 자동 복구, 기존 임시 저장 보존·가져오기.
- 작업 보관함: 새 상품, 작업 이름, 기존 작업 열기, JSON 가져오기·내려받기. 전환 전에 현재 작업 저장. 저장 실패 시 현재 내용과 이전 저장본을 유지하며 파일 내려받기 가능. 잘못된 JSON/중첩 편집값은 교체 전에 차단.
- 사용자 후속 요청으로 검정·골드 대문 추가. 마지막 작업 이어하기, 새 상품, 최근 작업 4개, 보관함 연결. 편집 중 새로고침은 편집 화면을 유지하고, 작업 홈으로 돌아오면 최근 목록 갱신. 390px/1440px 화면 확인.
- 복구에 실패한 문서는 덮어쓰지 않고 홈과 보관함에서 다른 정상 작업을 열 수 있도록 처리. 기존 안내 메시지가 사진 손잡이를 가리지 않도록 문구 영역은 포인터 통과, 닫기 버튼만 상호작용.

완료 검증: 새 기능 39항목(작업 흐름 12, 저장 실패/복구/파일 검증 13, 히스토리 규칙 8, 대문 6), 기존 회귀 49항목(사진 직접 편집 9, 제품 맞춤 13, 섹션 간격/800px 출력 17, 실제 누끼·보정 창 연결 10) 통과. 실제 JPEG에 조절 손잡이 없음, 사진 원본과 보정값 복구 확인. 별도 검토에서 발견한 잘못된 그림자 값 및 복구 실패 시 정상 작업 접근 문제를 재현 후 수정·재검증했다.

사용 범위: 저장은 같은 PC/같은 브라우저/같은 사이트 주소에 속한다. 클라우드 동기화는 추가하지 않았으며, 다른 환경으로 옮길 때 작업 JSON을 사용한다. 이미지 배치 기록은 현재 편집 세션에 한정되며 새로고침 후 배치 자체는 복원되고 취소 기록은 초기화된다. 실제 유료 AI 품질 재검사는 이번 범위에 포함하지 않았다. GitHub 푸시 및 Vercel 배포는 수행하지 않았다.
