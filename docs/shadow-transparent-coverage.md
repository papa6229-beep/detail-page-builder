# 투명 제품의 그림자 범위 보완

사용자 비교 화면: 원본의 접지 그림자는 자연스럽지만 누끼 후 새 그림자가 약하게 보임. 첨부 화면만으로 해당 사진의 알파를 확인할 수는 없으므로, 동일 사진의 최종 자연스러움은 재시험이 필요하다.

확인된 결함: 그림자 범위에 톤 통계와 같은 알파 180 기준을 사용해서 투명 몸체는 제외하고 불투명 받침만 포함할 수 있었다. 재현용 투명 몸체 아래 그림자 강도는 0/255였다.

수정: 그림자 전용 범위 계산을 분리하여 알파 16 이상을 포함한다. 미리보기와 저장 처리에 같은 계산을 사용한다. 누끼, 원본, 톤 통계, 그림자 농도·마스크·배치 기본값은 유지한다. 원본 사진의 그림자를 복원하는 기능은 아니다.

검증: 재현 검사 수정 전 실패, 수정 후 투명 몸체 아래 최대 알파 23/255. 불투명 제품 픽셀 변경 0. 기존 그림자 11항목 통과. 미리보기와 저장 PNG 비교, 이미지 실험실 및 본 빌더 빌드, TypeScript 검사 통과. 실제 사용자 원본 사진 재실행은 미확인.

## 접촉 그림자 개선 후속

사용자 요청에 따라 계속 진행. 기존 전체 실루엣을 압축한 그림자는 넓게 퍼지는 층으로 유지하고, 별도로 각 세로줄의 제품 아래쪽 윤곽을 추적한 짧은 접촉 그림자를 추가했다. 바닥 기준선에서 멀리 떠 있는 윤곽은 약하게, 투명 재질은 불투명 재질보다 옅게 처리한다. 두 마스크는 누끼가 바뀔 때만 생성하고 드래그 중에는 재사용한다. 기존 위치·가로·세로·각도·농도·부드러움 설정을 그대로 사용한다.

재현 검사: 바닥보다 약간 높은 몸체 바로 아래 최대 알파 2→38/255, 떨어진 영역 16/255. 투명 몸체 아래 최대 알파 54/255. 두 검사에서 불투명 제품 픽셀 변경 0. 총 28개 검사 통과(접촉 3, 투명 제품·미리보기/저장 3, 그림자 규칙 11, 실제 누끼 실행·드래그·크기·회전·PNG 11). 실시간 미리보기와 저장 PNG의 최대 채널 차이 0. CPU/GPU Canvas 필터 경로 사이의 작은 차이는 별도로 허용하며 실시간 미리보기와 해당 저장 PNG는 동일해야 한다.

수정 전 파일은 `2026-10-22-before-contact-shadow` 체크포인트에 보존. 동일 재현용 누끼를 이전 처리와 새 처리에 각각 넣은 비교 화면: 워크스페이스 `shadow-contact-comparison.png`. 실제 사용자 사진을 재구성한 이미지는 아니다. 열린 실험실에는 사진이 남아 있지 않아 사용자 원본 사진의 재시험은 포함하지 않는다. 원본 촬영 조명·그림자의 복원 기능은 추가하지 않았다.
