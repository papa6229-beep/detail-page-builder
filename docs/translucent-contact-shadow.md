# 투명 제품 접촉 그림자 보정

2026-10-22 사용자 비교 화면에서 투명 몸통 밑 그림자가 너무 옅다는 피드백을 확인했다. 원본 그림자는 누끼 과정에서 제거되며, 후보정은 제품 알파로 새 접촉/주변 그림자를 만든다.

투명 몸통(.3 알파)과 더 낮은 불투명 받침을 함께 가진 640×320 재현 이미지에서 기존 접촉 그림자 최대 알파는 21/255, 받침은 119/255였다. 투명도와 최하단 대비 높이 차이를 동시에 강하게 감쇠하던 것이 원인이다.

접촉 마스크에서 투명도 감쇠 지수 .5→.3, 높이 감쇠 거리 .22→.5로 조정했다. 전역 진하기/주변 그림자/제품 원본은 그대로 유지한다. 완전히 투명한 열은 계속 제외하며 불투명한 최하단 접촉은 기존 강도를 유지한다. 같은 재현에서 몸통 접촉 39/255, 주변 9/255, 받침 119/255. 새 테스트는 수정 전 21/255로 실패하고 수정 후 통과했다.

사용자 첨부 화면의 왼쪽 원본 영역을 별도 시험 입력으로 분리해 실제 누끼 모델과 후보정 흐름도 확인했다. 이는 첨부 화면 해상도에서의 확인이며 고해상도 원본의 정확한 그림자 복원을 의미하지 않는다. 첨부 사진과 시험 결과는 공개 저장소에 포함하지 않는다.

검증: 투명 몸통 접촉 5항목, 기존 접촉 3항목, 투명 제품/PNG/미리보기 일치 3항목, 이동·회전·진하기·폭·깊이·부드러움 등 11항목 통과. 불투명 제품 픽셀 변화 0, 미리보기/PNG 차이 0, CPU/GPU 출력 최대 차이 4/255로 기존 허용 8/255 이내.
