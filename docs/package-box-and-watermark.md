# 패키지 박스 이동 및 워터마크 범위 수정

사용자 피드백으로 패키지 디자인 적용 후 박스가 움직이지 않는 현상과 워터마크 이동 범위가 좁은 현상을 확인했다.

상세페이지와 썸네일 패키지의 Rnd가 사진 직접 편집 컨텍스트 존재만으로 drag/resize를 끄고 있었다. 두 곳을 박스 편집 기본값으로 복구하고 사진만 조절하는 모드를 분리했다. 썸네일 모드 버튼은 축소 캔버스 밖에 두어 화면에서 읽을 수 있는 크기로 유지하며, 박스는 배경 사진의 편집 영역보다 위에서 드래그를 받는다. 썸네일 축소 비율과 종횡비 잠금을 유지했다. 박스 제스처를 이미지 이력에 포함해 한 번에 실행 취소하고, 텍스트는 유지한다. 처음 측정할 때부터 좌표 기준 위치 스타일을 보장했다.

워터마크는 공통 사진 변환의 ±300% 위치 제한 때문에 작은 100px 로고를 300px 이상 움직일 수 없었다. 워터마크 키의 위치만 유한 범위 전체로 확대하고 일반 사진의 기존 제한·배율·회전 처리는 유지했다. 편집 중 워터마크는 사진 변환으로 조절하므로 비활성 Rnd 좌표 보정 대신 기존 x/y/크기를 가진 절대 위치 기준을 사용해 재열기 시 이동 오차도 방지한다. 기존 저장 수치의 단위는 바꾸지 않는다.

검증은 패키지 이동/리사이즈/실행 취소/사진 모드/새로고침, 축소 썸네일의 포인터 속도/비율/사진 모드/저장, 500×500 JPG에서 제품 유지 및 골드 조절 UI 제외, 100px 워터마크 600px 가로·450px 세로 이동/실행 취소/회전/재열기/초기화/제품 원본 유지로 구성한다. 이전 이력·옵션·모든 레이어 편집도 회귀 검사한다. 수정 전 소스 기준점은 `2026-10-22-before-package-box-fix`다.

실제 썸네일 모서리 드래그도 검사했다. 모서리 손잡이를 캔버스 안쪽에 두어 잘리지 않게 했고, overflow:hidden 캔버스가 포커스 시 내부 스크롤되던 문제는 overflow:clip으로 방지했다. 테두리/좌표 기준/box-sizing을 첫 측정부터 고정했다. 썸네일 박스 배치의 재열기 검사 및 JPG 제품 유지·조절 UI 제외 검사를 통과했다.
