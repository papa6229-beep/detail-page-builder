# 보정값 이어 쓰기와 미리보기 이미지 직접 편집

사용자 요청: 첫 사진의 보정값을 다음 사진에서 이어 쓰고, 배치된 이미지를 미리보기에서 마우스로 이동·비율 유지 크기 조절·회전한다. 기존 간격/제품 맞춤 기능은 유지한다. GitHub 푸시와 Vercel 배포는 하지 않는다.

- 복구 기준점은 보존하고 직전 제품 맞춤 상태도 `2026-10-22-before-preview-controls`에 별도 보관한다.
- 전체 이미지 보정에서 ‘다음 사진에도 이 보정값 사용’ 체크를 기본 켠다. 적용한 사진의 톤·그림자 모든 설정을 다음 사진 시작값으로 가져오며 체크 변경 자체로 현재 사진이나 누끼 결과를 초기화하지 않는다. 건너뛰기·원본 사용은 미적용 값을 전파하지 않는다.
- 미리보기의 실제 사진 위를 클릭/드래그한다. 선택한 한 사진에만 모서리 크기, 둥근 회전, 배치 초기화 조작을 보인다. 사각선·반투명 덮개는 쓰지 않는다. 편집 컨트롤은 출력에서 모두 제외한다.
- 실제 이미지 원본 문자열과 섹션 간격/예약 높이는 유지하며 이미지별 배치값을 저장한다. 기존 제품 맞춤은 기본 배치를 제공하고 그 위에서 직접 조절한다. 썸네일 보정은 네 규격에 비례 반영한다.
- 본문 메인/특징/포인트/사이즈, 패키지, 옵션, 썸네일/패키지, 워터마크에 공통 조작을 연결한다. 기존 Rnd와 중복 드래그가 발생하지 않게 한다. GIF 동영상 삽입은 기존 원본 애니메이션 출력으로 유지한다. 정지 삽입 이미지는 현재 보이는 결과를 JPG 중간 조각으로 출력한다.
- 사진 교체 시 해당 배치를 초기화하고 임시 저장/불러오기에서 유지한다. 기존 저장 데이터는 원래 배치로 표시한다. 이미지 원본과 모델 호출 방식은 바꾸지 않는다.

검증: 실제 누끼 3장 순차 처리의 설정 계승/해제/확정 전 원본 유지, 사진별 마우스 이동·회전·회전 후 크기·초기화, 제품 맞춤 병행, 축소 썸네일 좌표·독립성, 옵션/패키지/로고, 저장/불러오기·사진 교체, 실제 JPG/ZIP 출력과 컨트롤 제외, 기존 드롭·간격·오타 선택 수정 회귀, 빌드/타입 및 화면 확인.

완료 확인: 순차 처리 5개, 직접 편집/실제 JPG/저장 복구 9개, 레이어 위치/회전 6개, 배치값 규칙 6개, 삽입 이미지와 GIF ZIP 출력 4개, 제품 맞춤 13개, 기존 이미지 보정 연결 10개, 업로드 18개, 섹션 간격 17개, 오타 선택 적용 10개 통과. 500×500 JPG의 실제 회전은 약 5.003°로 확인했고 금색 편집 UI 픽셀은 0개였다. 정지 삽입 이미지는 800×490 JPG로, GIF는 원본 바이트 그대로 ZIP에 저장되는 것을 확인했다.

선택 시 미리보기 헤더가 높아지며 사진이 튀는 현상을 재현한 뒤 고정 높이로 수정했다. 미리보기 헤더는 스크롤을 따라가며 선택 이미지 초기화 버튼을 제공한다. 편집값은 원본 파일·간격·예약 높이를 바꾸지 않는다. 두 복구 기준점은 유지하며 푸시·배포는 하지 않는다.
