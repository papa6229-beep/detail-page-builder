# 그림자 회전·선택 오타 검수

2026-10-22 사용자 요청: Adobe 링크 제거, 마우스로 그림자 각도 변경, 우상단 전체 텍스트 오타 검수 및 사용자가 선택한 수정만 적용.

- 기존 투명 이동 영역과 크기 손잡이를 유지한다. 둥근 회전 손잡이를 드래그하면 그림자만 중심을 기준으로 회전한다. 회전 후에도 크기 조절 방향이 손잡이와 일치한다. 각도는 이미지별 설정과 임시 저장에 포함하고 이전 설정은 0도로 읽는다.
- 검수 대상은 입력한 상품명·영문명·브랜드·스펙·옵션명·요약·섹션 제목·설명이다. 이미지·원본 메타데이터는 전송하지 않는다.
- 기존 OpenRouter 연결과 저비용 Gemini 2.5 Flash Lite를 사용한다. 로컬에 연결 키가 없어 비밀번호 입력란을 제공하며 메모리에서만 유지한다. 기존 환경변수가 있으면 재사용한다. 실제 유료 검수는 사용자가 실행한다.
- 명확한 오타·중복·띄어쓰기 후보를 JSON으로 받고, 상품군 은어·상품명·브랜드·비사전 표현을 단순히 사전에 없다는 이유로 바꾸지 않도록 지시한다. 문체 변경·사실·수치·단위 변경을 요청하지 않는다.
- 결과는 원문 일부 → 수정안·이유로 표시한다. 체크 기본값은 모두 해제. 선택 적용 외에는 본문을 바꾸지 않는다. 동일한 단어의 반복 위치를 구분하고 겹치는 후보 및 원문에 없는 후보는 걸러낸다. 검수 후 원문이 달라진 필드는 적용하지 않는다.
- 본문 안의 지시는 자료로 취급한다. 입력 길이·응답 형식·오류·취소를 처리하며 자동 재시도로 요금을 늘리지 않는다.

검증: 회전 중 반영·회전 후 크기 조절·저장 PNG 일치, 예전 각도 없는 설정, Adobe 링크 없음, 편집 필드 수집, 반복·겹침·오래된 결과 방어, 선택 항목만 반영, API 오류·빈 결과·키 미입력·취소. API는 모의 응답으로 검사하고 실제 모델 교정 품질은 미검증으로 구분한다.

모델 확인: OpenRouter 공식 모델 카탈로그에서 google/gemini-2.5-flash-lite 및 response_format·structured_outputs 지원 확인(유료 요청 없음). 선택 적용을 누르면 편집기로 돌아가고, 적용 개수와 원문 변경으로 건너뛴 개수를 안내한다. 전체 텍스트를 자동으로 수정하는 동작은 없다.
