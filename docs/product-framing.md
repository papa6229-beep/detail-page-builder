# 제품 크기 맞춤 — 첫 추가 개선

사용자 승인: GitHub 푸시·Vercel 배포 시점은 사용자가 정한다. 추가 개선은 우선 메인 사진·썸네일의 제품 크기 맞춤부터 진행한다. 복구 기준점 `2026-10-22-approved-before-next`는 변경하지 않는다.

- 기존 검정·금색 입력 UI와 실제 사진을 유지한다. 생성·재채색·픽셀 편집 없이 배치값만 저장한다.
- Main Image와 Thumbnail에 ‘제품 크기 맞춤’, 적용 후 ‘맞춤 해제’를 둔다. 썸네일 사진이 비어 있으면 현재와 같이 메인 사진을 사용한다.
- 사진의 투명 여백을 제외한 보이는 영역(그림자 포함)을 계산한다. 배경이 꽉 찬 사진이나 빈 이미지에서는 적용하지 않고 누끼 보정을 안내한다. 사이즈표·설명 사진은 건드리지 않는다.
- 메인은 맞춤을 눌렀을 때만 사진 영역 비율을 제품에 맞춰 조정한다(0.8~2.5). 썸네일은 기존 202/400/500/274x411 규격과 브랜드 문구 공간을 유지한다.
- 맞춤 후 제품을 직접 끌어 위치를 조절하고 바깥쪽 작은 손잡이로 비율을 유지하며 크기를 조절한다. 사각 편집선은 표시하지 않는다. 보이는 영역을 화면 밖으로 잘라내지 않도록 배치를 제한한다.
- 메인과 썸네일의 배치는 독립적이며 썸네일 배치는 네 규격에 비례 적용한다. 저장·불러오기 시 유지하고 사진 교체·보정 적용 시 해당 배치를 초기화한다. 기존 저장 파일은 원래 배치로 표시한다.
- 모든 저장 JPG에서 편집 손잡이를 제외한다. 원본 이미지 문자열·워터마크·텍스트·다른 섹션은 유지한다.

검증: 여백이 큰 비대칭 누끼 fixture로 자동 크기/중심, 직접 이동/비율 유지 크기, 메인·썸네일 독립성, 네 규격의 문구 공간, 실제 JPG 크기/배치/손잡이 제외, 저장/불러오기/초기화/사진 교체, 불투명·빈 사진 방어 및 기존 업로드·간격 검사. 새 외부 호출·유료 AI 호출·의존성 추가 없음.
