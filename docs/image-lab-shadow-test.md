# 그림자 조절 테스트 범위

2026-10-22. 사용자 승인: 테스트 환경을 먼저 패치하고, 시각적으로 적당한지 확인한 다음 본 빌더에 적용한다.

- 현재 누끼 결과를 그대로 재사용한다. 제품의 색·형태·해상도는 그림자 설정으로 바뀌지 않는다.
- 납작한 타원 대신 제품 알파를 바닥 방향으로 압축한 부드러운 그림자와 짧은 접촉 그림자를 합성한다. 원본 사진의 그림자 복원은 포함하지 않는다.
- 테스트 화면의 패널에는 그림자 켜기, 진하기, 부드러움과 기본값 복구를 둔다. 2026-10-22 후속 요청에 따라 위치는 결과 위 조절 상자 드래그, 크기는 가장자리·모서리 손잡이 드래그로 바꾼다. 방향키로도 미세 조절할 수 있다.
- 누끼와 톤이 적용된 제품 및 알파 마스크를 캐시하고, 조작 중에는 다음 화면 프레임에 그림자만 다시 그린다. 손을 놓거나 조절을 멈추면 원본 해상도의 저장용 PNG를 별도로 만든다. 조절 상자와 손잡이는 저장하지 않는다.
- 원본 크기를 유지하므로 이미지 가장자리 밖으로 이동한 그림자는 잘릴 수 있음을 화면에 표시한다.
- 그림자 픽셀 강도·이동·크기·투명도·제품 픽셀 보존을 브라우저에서 검증한다. 실제 누끼 → 조절 → PNG 저장 흐름과 빌드를 확인한다. 최종 자연스러움은 사용자의 원본 사진으로 판단한다.

검증: 그림자 회귀 테스트, 마우스를 누른 상태의 이동·크기 변경·농도 반영, 원본 크기 미리보기와 저장 PNG 일치, 축소 미리보기의 흐림 정도 일치, 기본값·켜기/끄기, 누끼 재계산 없음, 실제 모델 실행과 빌드.

다음 연결 방향(이번 패치에는 미포함): 각 이미지 삽입 영역에서 개별 적용, 우상단에서 상세페이지 전체 이미지를 하나씩 순차 처리. 테스트 승인 후 동일한 처리 함수와 설정을 연결한다.
