# 이미지 보정 본 빌더 연결

사용자 승인(2026-10-22): 편집 틀이 그림자를 가리지 않도록 고친 뒤 테스트한 보정 기능을 적용한다. 기존 합의: 이미지별 편집 및 우상단에서 전체 이미지를 순차 처리.

- 그림자 위의 사각선·배경·이동 라벨은 제거한다. 투명한 이동 영역과 바깥쪽 크기 손잡이는 유지한다.
- 테스트 화면의 처리 컴포넌트를 재사용한다. CSS 범위를 제한해 본 빌더·상세페이지 스타일에 영향을 주지 않는다.
- 각 상품 사진에 누끼·보정 버튼을 추가한다. 우상단 전체 이미지 보정은 실제 첨부한 사진을 순서대로 열어, 적용 또는 건너뛰기로 진행한다. 워터마크 로고와 GIF는 원본을 유지한다.
- 적용 전에는 원본 슬롯을 바꾸지 않는다. 적용한 사진의 원본과 설정을 저장하고, 원본 복구와 재편집을 지원한다. 누끼 결과는 세션 캐시에 재사용한다. 새 파일로 교체하면 해당 사진의 이전 보정 정보를 비운다.
- 닫기는 현재 사진의 미적용 변경을 버린다. 앞서 적용한 사진은 유지한다. 슬롯 식별에는 옵션의 고유 ID를 사용한다.
- 필요한 브라우저 격리 헤더를 개발/미리보기 및 배포 설정에 둔다. 기존 외부 스타일·글꼴 로딩을 실제 브라우저에서 확인한다. 배포·푸시는 이번 작업에 포함하지 않는다.

순서: 회귀 검사 실패 확인 → 편집 틀 조정 → 공통 처리 컴포넌트와 CSS 범위 분리 → 슬롯·원본 상태 관리 및 모달 연결 → 개별/순차/복구/교체/취소·실제 누끼·저장·기존 드롭·간격 검사 → 빌드와 화면 확인.

검증 결과: 본 빌더 연결 10개(실제 모델 실행, 적용 전 원본 유지, 조절값 보존, 임시 저장/불러오기, 원본 복구, 순차 처리, 건너뛰기, 닫기, 파일 교체), 슬롯 관리 4개, 그림자 9개, 드래그/저장 일치 9개, 이미지 처리 전체 흐름 12개, 기존 업로드 18개, 섹션 간격 17개 통과. 본 빌더에서 crossOriginIsolated=true 확인. 그림자 위 사각선·배경·이동 라벨이 없는 것을 CSS와 브라우저에서 확인.
